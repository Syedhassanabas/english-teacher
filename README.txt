1. GEMINI_API_KEY: aistudio.google.com se free key banayein.
2. Ye poora folder GitHub repo mein upload karein.
3. Netlify > Add new site > Import from Git > repo chuniye > Deploy.
4. Site settings > Environment variables: GEMINI_API_KEY = aapki key (deploy se PEHLE ya baad mein add karke redeploy).
5. Optional: GEMINI_MODEL = model ka naam (default gemini-2.5-flash).
